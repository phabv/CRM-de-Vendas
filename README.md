# CRM de Vendas

Projeto acadêmico desenvolvido em grupo com o objetivo de aplicar conceitos de Programação Orientada a Objetos no desenvolvimento de um sistema de gerenciamento de vendas.

## Sobre o projeto

O CRM de Vendas tem como objetivo apoiar o gerenciamento de informações relacionadas ao processo comercial. O projeto já possuía parte de sua estrutura implementada, e o trabalho consistiu em contribuir para sua evolução aplicando os conceitos estudados durante a formação acadêmica.

## Minha contribuição

Minha responsabilidade no projeto foi desenvolver a camada **Service**, trabalhando na organização da lógica de negócio e na separação de responsabilidades entre as camadas da aplicação.

Durante o desenvolvimento, o foco foi compreender a arquitetura existente, integrar a implementação ao código do grupo e aplicar os conceitos de Orientação a Objetos de acordo com as necessidades do sistema.

## Conceitos estudados

- Programação Orientada a Objetos (POO)
- Separação de responsabilidades
- Organização da lógica de negócio
- Integração entre camadas da aplicação

## Aprendizados

O desenvolvimento deste projeto contribuiu para minha compreensão sobre organização de código, responsabilidades de uma camada de serviço e integração de funcionalidades em uma aplicação existente.

Também foi uma oportunidade de trabalhar com código desenvolvido em equipe e aprofundar meu entendimento sobre a aplicação prática dos conceitos de Orientação a Objetos.
